# Robotics Society Arduino Workshop
There are 2 files in this repo: an example file that does not need edited .../ArduinoWorkshop and a file for you to fill in the blank code .../ArduinoWorkshopGappedCode.
You will need to click the green code button at the top of this page and click download .zip, this will be a zip file with both versions of the code. 
Once the zip file is downloaded extract it in a safe place.

To edit the code and run it on the Arduino you will need the ['Arduino IDE'](https://www.arduino.cc/en/software/).
Then you can start the IDE and open the folder of the file you wish to use.
Good Luck!!

### After Event
Due to the issued had with the ultrasonic sensors on the first night, they were switched out with LDRs. This change makes the circuit more reliable and also uses a wider variety of features including the analogue pins. 

If you don't have a kit you can try this same circuit using TinkerCad ['TinkerCad'](https://www.tinkercad.com/)
